# Victoria Wild Loop · 2026

用于 2026 年维多利亚州自然生态环线的纯静态行程网站。

## 本地预览

直接打开 `index.html`，或使用任意静态文件服务器预览。网站不依赖构建步骤。

## 发布

推送至 `main` 分支后，在 GitHub 仓库 **Settings → Pages** 中选择 **Deploy from a branch / main / (root)**。发布地址为：

`https://edgew.github.io/Australian-trip/`

## 图片与资料

- 景点主图由前端按对应 Wikipedia 词条实时请求其摘要主图；该主图来自 Wikipedia / Wikimedia Commons，并在页面内展示来源链接。
- 行程内容忠实整理自原始确认版；出发前仍须以 Parks Victoria、运营方与道路/天气公告为准。
